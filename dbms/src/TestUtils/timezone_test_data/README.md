These public-domain TZif fixtures pin the timezone conversion tests to IANA tzdata
2024a. In particular, Apia no longer observes DST in 2026, and Vostok has the 1994
seven-hour gap used to test TiDB's four-hour adjustment threshold.

`TimeZoneTestData.cpp` exposes them through cctz's zone-info source extension under
`tiflash_test_2024a/`. Normal timezone names use the default loader. Tests do not
change TZDIR, clear caches, require source files at runtime, or use host tzdata
for fixture names. UTC retains cctz's built-in fixed zone.

To regenerate (zic 2.35 was used):

```sh
curl -fLO https://data.iana.org/time-zones/releases/tzdata2024a.tar.gz
# SHA256: 0d0434459acbd2059a7a8da1f3304a84a86591f6ed69c6248fffa502b6edffe3
mkdir tzdata2024a
tar -xzf tzdata2024a.tar.gz -C tzdata2024a
cd tzdata2024a
zic -b fat -d zoneinfo africa antarctica asia australasia europe northamerica southamerica etcetera backward
# Run from the repository root, using this zoneinfo directory:
python3 dbms/src/TestUtils/timezone_test_data/generate.py /path/to/tzdata2024a/zoneinfo > dbms/src/TestUtils/timezone_test_data/zones.inc
```

Keep the generated bytes in the repository. Tests must not download or regenerate
them at build or runtime. Updating the data version also requires updating the
fixture prefix and the expected transition results.
